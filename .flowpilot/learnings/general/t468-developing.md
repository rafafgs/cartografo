### t468 (developing, unverified)

- NODE_TEST_CONTEXT must be DELETED from the harness child's environment. Inherited, it puts the child's node:test into the serialized-reporter mode a test-runner subprocess uses: the output the parent quotes on failure comes back as binary, and the child's exit decision changes (my first run exited early and hid the hang). NODE_OPTIONS goes too, per bin.e2e.test.ts's own rule.
- The Promise.race ceiling must be aborted AFTER the race resolves, never chained onto the winner via .finally(() => abort()): finally adds microtask ticks while the abort-derived rejection resolves in one, so the abort's own null can win the race and report a timeout the harness never had. Left unaborted entirely, the timer holds the event loop for the whole remaining bound — 20.2s of wall clock for a 3.5s test.
- HARNESS_BOUND_MS has to stay well under C4's own hardcoded timeoutSeconds: 60. Past that the ShellAdapter's internal wall clock calls its OWN real cancel (not the decorator's override) and takes the group down, so a hung harness starts to look reaped and the regression test would go green on the bug. 20s is the chosen ceiling.
- The regression test deliberately does NOT import the fixture module — the side-channel env var name is a literal in both files with a cross-reference comment. Importing it would register the conformance kit in the parent's process and run the C4 that is supposed to fail. Same reason the harness is spawned as plain `node <fixture>.ts` rather than `node --test`.
- The fixture is the package's first .ts file under test/fixtures/ (everything there was .mjs). It is safe because the package's test script globs test/**/*.test.ts, so the fixture is never auto-collected — but it IS inside tsconfig's include and eslint's sweep, so it has to typecheck and lint like source.
- AT1 deliberately does not probe with a SIGTERM before reaping: the stub's SIGTERM handler is installed on its own first tick, so a signal sent from the test races that tick and would occasionally kill the process, turning the case red for a reason unrelated to the reaper. The immunity is by construction, and the one-liner is kept byte-identical to fake-engine.mjs's so a `ps` census greps for the same string.
- `let record: FakeRecord;` with no initializer, read inside the t.after closure, typechecks clean under strict — TS does not carry definite-assignment analysis across a function boundary. No `!` or `as` needed.
